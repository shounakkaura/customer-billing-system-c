# Customer Billing System in C

A beginner-friendly customer billing system built using the C programming language. This project aims to practice programming fundamentals by creating a simple billing application.

## About the Project

The Customer Billing System is a console-based application designed to calculate customer bills based on purchased items and their prices.

This project is being developed to strengthen my understanding of C programming, including variables, conditional statements, loops, functions, and basic data handling.

## Features

Planned features:

- Customer details input
- Item name, quantity, and price input
- Automatic calculation of item totals
- Calculation of the final bill
- Display of an itemized bill
- Input validation for basic errors

Features will be marked as completed as they are implemented.

## Technologies Used

- **Language:** C
- **Compiler:** GCC
- **Development Environment:** Visual Studio Code

## Getting Started

### Prerequisites

To compile and run this project, you need:

- A C compiler such as GCC
- A code editor such as Visual Studio Code, or a terminal

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/shounakkaura/customer-billing-system-c.git
   ```

2. Navigate to the project directory:

   ```bash
   cd customer-billing-system-c
   ```

3. Compile the program (once `main.c` is added):

   ```bash
   gcc main.c -o billing
   ```

4. Run the program:

   **Windows:**
   ```bash
   billing.exe
   ```

   **Linux/macOS:**
   ```bash
   ./billing
   ```

## How It Works

The application will take customer and purchase details as input, calculate the applicable item totals, and display the resulting bill.
